# 🎵 UA Music Bot & AI Content Generator

Універсальний Telegram-бот та консольний інструмент для спільноти **UA Music**:
1. **Заміна обкладинок MP3**: швидке оновлення тегів ID3v2 та мініатюр аудіофайлів для Telegram.
2. **AI-генератор постів (Google Gemini API)**: створення захопливих музичних оглядів, рецензій та описів українською мовою з YouTube або фото/обкладинок.
3. **Автоматичні коментарі каналу**: залучення аудиторії в групі обговорень під музичними публікаціями.
4. **Консольний менеджер (`console.py`)**: локальне генерування, перегляд та редагування бази постів (`posts.json`).

---

## 📁 Структура проєкту

```text
UA Music/
├── core/                       # Базові моделі та конфігурація
│   ├── config.py              # Налаштування шляхів та Gemini
│   ├── models.py              # Pydantic-моделі постів (PostItem, PostStatus)
│   └── storage.py             # Збереження постів у posts.json
├── handlers/                   # Обробники подій для Aiogram
│   ├── autobot.py             # Команди AI: /song, фото, /posts, /review, /edit, /approve, /delete
│   ├── channel.py             # Автоматичні коментарі під музичними постами
│   ├── music.py               # Обробка MP3 та встановлення обкладинки
│   ├── profile.py             # Команда /id
│   └── rules.py               # Команда /rules (правила спільноти)
├── services/                   # Бізнес-логіка та сервіси
│   ├── files.py               # Завантаження файлів з Telegram
│   ├── gemini_service.py      # Генерація текстів та аналіз зображень через Gemini API
│   ├── music.py               # Робота з ID3, Pillow, тегами та обкладинками
│   ├── post_generator.py      # Пайплайн створення та керування постами
│   └── youtube_service.py     # Витягування метаданих YouTube через yt-dlp
├── bot.py                      # Головна точка входу для єдиного Telegram-бота
├── console.py                  # Інтерактивна CLI-консоль для генерації та редагування
├── gemini_client.py            # Клієнт для роботи з Gemini API
├── gemini_demo.py              # Демонстраційний скрипт можливостей Gemini
├── posts.json                  # Локальна база збережених постів
├── requirements.txt            # Усі залежності проєкту
└── .env                        # Ключі API та конфігурація середовища
```

---

## ⚙️ Налаштування (.env)

У кореневій папці створено файл `.env`:

```env
# Gemini AI
GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=gemini-3.5-flash-lite

# Telegram Bot
TOKEN=your_telegram_bot_token
CHANNEL_USERNAME=your_channel_username
```

---

## 🚀 Запуск

### 1. Встановлення залежностей
```bash
pip install -r requirements.txt
```

### 2. Запуск Telegram-бота
```bash
python bot.py
```

### 3. Запуск консолі генерації та рецензування постів
```bash
python console.py
```

## 🤖 Команди Telegram-бота

| Команда | Опис |
|---|---|
| `/start` | Привітання та огляд можливостей бота |
| `/help` | Список усіх доступних команд |
| `/song <посилання/назва>` | Генерація атмосферного посту про трек через Gemini AI |
| *Надіслати фото* | Аналіз обкладинки/фотографії та генерація посту |
| `/posts` | Перегляд списку останніх збережених постів |
| `/review <id>` | Повний перегляд тексту посту та його статусу |
| `/edit <id> <новий текст>` | Редагування тексту збереженого посту |
| `/approve <id>` | Затвердження посту (`status: approved`) |
| `/delete <id>` | Видалення посту з `posts.json` |
| *Надіслати MP3* | Запуск процесу встановлення нової обкладинки |
| `/cancel` | Скасування поточної операції заміни обкладинки |
| `/rules` | Правила спільноти каналу |
| `/id` | Отримати свій Telegram ID |
